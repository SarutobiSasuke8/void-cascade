# Sprite Status

Single source of truth for **what art exists and what still needs making**. Update the
status column in the same change that adds or wires a sprite; add a row to
`assets/CREDITS.md` at the same time.

Conventions (see `docs/ASSET_PIPELINE.md`): square RGBA PNG, transparent background,
**1254×1254 masters**, authored **facing right / nose toward +X** for anything that
rotates. Everything not yet drawn renders from a procedural fallback in code, so the
game is always playable — a missing sprite is a downgrade, never a crash.

**Status key:** ✅ done · 🔲 needed · ➖ procedural by design (do not draw)

4. **Torpedo + multiplier pickups** — the last two procedural placeholders in a set
   where the other four are finished art
5. Boss-wave background — nice to have, lowest risk to skip
